# Kassensystem

Offline-fähige Kassen-PWA für Events, gebaut mit React + TypeScript + Vite.

## Links

- **App**: [geiserrafael.github.io/kassensystem](https://geiserrafael.github.io/kassensystem/)
- **Firebase Console (Firestore)**: [console.firebase.google.com](https://console.firebase.google.com/project/kassensystem-9f873/firestore/databases/-default-/data/~2Fproducts~2F10)

## Tech Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Dexie.js (IndexedDB, offline-first)
- Zustand (Cart State)
- Firebase Firestore + Anonymous Auth (Cloud Sync)
- vite-plugin-pwa (Service Worker + PWA Manifest)
- GitHub Pages via GitHub Actions
